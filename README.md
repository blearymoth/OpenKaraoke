# OpenKaraoke

Self-hosted web karaoke for Linux. Plays your own CDG+MP3 / MP4 karaoke library (tested with ~90,000 tracks) from a USB drive, with:

- a KaraFun-style host app, a TV display on a second screen, and a phone app for guests who join by QR code
- key change and tempo control, singer rotation, request approval, favourites, playlists and history
- cover art and artist images matched from online music databases and cached locally
- party games: singing battles with audience voting, a music quiz, a roulette wheel and more

> Work in progress — full setup instructions will be added as the first version lands.
